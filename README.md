# Zaur Mamedov — Code. Drive. Play.

Персональный сайт к 25-летию Заура: Java, автомобили, сюжетные игры и азербайджанские и турецкие детали.

## Запуск

Node.js 22+, установка зависимостей не нужна.

```sh
npm run check
npm run dev
```

Открыть http://127.0.0.1:4173. Для 3D нужен HTTP-сервер, а не file://.

## Размещение

Готовый сайт находится в `dist/`. Опубликуйте содержимое этой папки на статическом хостинге. Корневой `index.html` перенаправляет в `dist/`, если хостинг обслуживает весь репозиторий. Загрузка в GitHub сама по себе не включает GitHub Pages.

Основные файлы: `portfolio.css`, `portfolio.js`, `drive.js`. Локальные библиотеки, фотографии, иллюстрации, 3D-модель и Draco находятся в `dist/assets/`. Шрифты загружаются из Google Fonts с системной заменой. Музыка синтезируется в браузере после нажатия кнопки звука.

Описание и промпты: `PORTFOLIO-V3.md`. Портрет — растровая иллюстрация; автомобиль — интерактивная 3D-модель. Атрибуция: `dist/assets/ATTRIBUTION.txt`.

Прежний HTML сохранён в `archive/original-index.html`; его изображения, аудио и видео оставлены в исходных папках и истории Git. Архив личной переписки не включён.
